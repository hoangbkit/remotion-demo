# Remotion Demo

A simple 10-second animated promo video built with Remotion.

## Run locally

```bash
npm install
npm run dev
```

Open the Remotion Studio preview in your browser and select the `Demo` composition.

## Render an MP4

```bash
npm run build
```

The rendered video will be written to `out/demo.mp4`.

## Composition

- Resolution: 1920 × 1080
- Frame rate: 30 FPS
- Duration: 300 frames (10 seconds)
